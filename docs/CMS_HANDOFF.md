# Замки — інструкція по CMS-адмінці (Handoff G9)

Мови вітрини: **UA / RU** (код `ua` / `ru`). Якщо RU порожній — показується UA.  
Адмінка: `/admin/`

---

## Що змінюється без деплою

Усе **значення** контенту в адмінці (тексти, фото, видимість секцій, SEO полів товару, контакти).

Після «Зберегти» зміни одразу на сайті (після оновлення сторінки).

---

## Що потребує розробника / деплою

- Нова **секція** або новий **ключ** контенту (немає пункту в сайдбарі)
- Нова сторінка в карті сайту
- Нові типи товарів / фасетів у логіці фільтрів
- Інтеграції (Нова Пошта, оплата) — ключі лише в **env**, не в БД
- Waitlist — не підключено

---

## Сайдбар адмінки

### Налаштування
| Пункт | Що редагувати |
|--------|----------------|
| Контакти та SEO | Телефон, email, адреса, графік, соцмережі, SEO за замовчуванням, лого |
| Медіатека | Спільні фото (WebP). Потім можна обрати в банері |

### Головна (порядок ≈ як на сайті)
Банер → Для кого → Категорії → Підбір → Популярні → Блог → Район SEO

- **Банер** — слайди (фото з Медіатеки або upload, alt UA/RU, посилання)
- Інші пункти — тексти секцій + «Показувати секцію»

### Оболонка сайту
| Пункт | Зміст |
|--------|--------|
| Шапка | Підписи каталогу/пошуку/кнопки, видимість іконок |
| Підвал | Колонки, про нас, copyright |

### Інфосторінки
Про нас, Доставка, Гарантія, Обмін, Установка, Акції, Оферта, Політика — заголовок, лід, текст (TinyMCE), SEO.

### Каталог (CMS)
Оболонка PLP (заголовок / порожній стан / фільтри).

### Каталог (товари)
Товари, Категорії, Сімʼї, Фасети — бізнес-дані.  
У товарі вкладки: **Основне → Опис → Фото → Фасети → SEO** (UA/RU поля з суфіксом `_ru`).

### Замовлення / Заявки
Замовлення, швидкі замовлення, райони; форми контактів, передзвону, монтажу, підбору за фото; блог.

---

## Мови в формах

У CMS-секціях — вкладки **Українська / Російська** (поля не одне під одним).  
Порожній RU = на сайті береться UA.

---

## Тема сайту (відвідувач)

Кнопка сонце/місяць у шапці.  
- Світла: білий + помаранчевий + жовтий  
- Темна: чорний + помаранчевий + жовтий  
Зберігається в браузері (`localStorage`). Не керується з адмінки (окремо від бренд-кольорів).

---

## Команди для команди розробки

```bash
python3 manage.py migrate
python3 manage.py seed_content          # ідемпотентний CMS seed
python3 manage.py seed_content --check  # parity 99 блоків / 4 hero
python3 manage.py cms_audit_manifest    # G8 audit (blockers=0)
python3 manage.py check
```

На Vercel bootstrap додатково викликає `seed_cms_content` після `seed_demo`.

---

## Відомий борг (не блокує адмінку)

- ~179 `{% t %}` у шаблонах (навігація, каталог, модалки) — ще не всі рядки в CMS  
- Повний kill: `cms_audit_manifest --strict-warn`  
- Info-сторінки: тіло може бути порожнім до заповнення редактором  
- Waitlist відсутній  

---

## Швидкий чеклист редактора

1. Увійти в `/admin/`  
2. Головна → Банер — перевірити слайди  
3. Налаштування → Контакти — телефон/графік  
4. Змінити RU-вкладку → перевірити `/ru/`  
5. Товар → SEO вкладка  
6. Вимкнути секцію галочкою «Показувати» → зникла на головній
